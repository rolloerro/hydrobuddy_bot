💧 HydroBuddy

HydroBuddy — простой и дружелюбный Telegram-бот, который помогает не забывать пить воду.
Потому что вода = жизнь, а обезвоживание — тихий враг продуктивности 🧠💀

🚀 Возможности

⏰ Напоминания пить воду

📊 Учёт выпитой воды

💬 Лёгкий, ненапряжный формат общения

🧠 MVP без лишнего — быстро и по делу 

🛠 Технологии

Python 3.12

aiogram 3

JSON-хранилище (MVP-уровень)

📦 Установка и запуск
1️⃣ Клонировать репозиторий
git clone https://github.com/rolloerro/hydrobuddy_bot.git
cd hydrobuddy_bot

2️⃣ Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # macOS / Linux
venv\Scripts\activate     # Windows

3️⃣ Установить зависимости
pip install -r requirements.txt

4️⃣ Запустить бота
python bot.py

🔐 Важно

НЕ коммить venv/

НЕ публикуй токены и .env

Используй .gitignore (он уже есть 👌)
